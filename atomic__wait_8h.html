atomic_notify_32
int atomic_notify_32(volatile atomic_uint_least32_t *__restrict object, uint_least32_t *__restrict expected, uint_least32_t desired, unsigned max_threads_to_wake, memory_order success, memory_order failure)

Atomically compare-exchange and notify up to max_threads_to_wake waiters.

sizeof(*object) must equal sizeof(uint_native_wait_notify_t). Performs atomic_compare_exchange_strong_explicit. If *object still equals *expected, replaces it with desired and wakes up to max_threads_to_wake waiting threads. On some platforms the return value may be 1 plus the number of threads woken.

Parameters
objectPointer to a volatile _Atomic uint_least32_t.
expectedPointer to value compared against; updated on failure.
desiredValue to store on successful exchange.
max_threads_to_wakeMaximum number of waiters to wake.
successMemory order on success.
failureMemory order on failure.
Returns
Positive (1 + woken count) on successful exchange; zero on failure; negative on error.
Return values
>0Successful exchange and notify.
0Compare-exchange failed.
<0Error.

atomic_wait_expected_32
int atomic_wait_expected_32(const volatile atomic_uint_least32_t *__restrict object, uint_least32_t *__restrict expected, const struct timespec *__restrict duration, memory_order success, memory_order failure)

Wait up to duration for *object to no longer equal *expected.

sizeof(*object) must equal sizeof(uint_native_wait_notify_t). If *object does not equal *expected, returns immediately. Otherwise suspends the thread until notified or until duration passes. On wake, re-compares; if still equal, parks again. Total accumulated wait is at least *duration. On return, *expected is updated to the most recently loaded value.

Parameters
objectPointer to a volatile _Atomic uint_least32_t.
expectedPointer to value to compare against; updated on return.
durationMaximum time to wait, or NULL for no timeout.
successMemory order when the wait ends with value != *expected.
failureMemory order on timeout or early mismatch.
Returns
Zero if no suspension or timeout; positive if suspended at least once; negative on error.
Return values
0No suspension occurred, or duration timeout.
>0Thread was suspended at least once.
<0Error.

◆ uint_native_wait_notify_t

typedef uint_least32_t uint_native_wait_notify_t

Smallest unsigned integer type suitable for atomic wait/notify on this platform. Always uint_least32_t.

sizeof(uint_native_wait_notify_t) is guaranteed to be 4 bytes, the largest atomic width supported by all WG14-compliant platforms.
